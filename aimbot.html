Aimbot

Aimbot automatically aims at targets. After enabling Weapon Group, each weapon type gets its own independent configuration; otherwise the Global setting is used. Aimbot settings are split into the "Aimbot" section and the "Limits" section, described below.

Weapon Group

A separate configuration set for each weapon type. Uses the independent configuration after Aimbot Enabled is on; otherwise falls back to the Global setting.

Enabled

Master switch for the Aimbot feature.

Mouse Sync

Aimbot only works while the mouse is moving.

Activate

Activation mode: "on Attack" works while the left mouse button is held; "Always" works at all times.

Mode

"Normal" visibly and smoothly moves the view — the mode used in most cases. "Silent" aims silently in your local view, but spectators can see the view move. "Perfect Silent" aims silently both locally and on the server, so spectators cannot see the view move either.

Move

"Normal" moves the view at a constant speed. "Decrease" slows down as it gets closer to the target. "Ease in and out" adds easing at the start and end of aiming.

Precise

Improves Aimbot precision to increase hit rate.

Humanized

Master switch and settings for humanization, making the aim trajectory closer to a real person:

  • Start Speed: The starting speed of the Aimbot aim.
  • Stop Speed: The stopping speed of the Aimbot aim.
  • Line Deviation: Randomly adds curvature while aiming.
  • Random Smooth: Randomly accelerates and decelerates while aiming.
  • Random Hit Point: Picks a random point as the target point each time it aims.
  • Reaction Speed: Delays the allowed Aimbot work by a specified number of milliseconds after spotting a target; also affects the aim trajectory.

AutoMatic

Switches the firing mode to fully automatic.
