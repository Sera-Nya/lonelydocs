Aimbot Limits

The following settings constrain the Aimbot's working range and speed, improving stealth and stability.

Aim Time Limit

Limits how long the Aimbot can aim; when Humanized is enabled, it adds an ease-out effect when the Aimbot stops.

Distance

Filters out targets beyond the specified distance.

Smooth

Controls the Aimbot aim speed; higher values are slower.

Predict

Predicts the future position of the target point using target velocity, latency, and the lerp value.

Hit Chance

Calculates hit chance from weapon spread and the target hitbox; only aims when the hit chance is above the set value.

Delay Shoot

Delays firing by a specified number of milliseconds after the fire key is pressed, preventing premature shots before the Aimbot has aimed at the target. Recommended.

First Slow

Slows down while firing to mimic the aim slowdown caused by holding the left mouse button; when Delay Shoot is enabled, it activates 20 ms earlier.

Rapid Fire

After firing, uses right-click pushes to override the fire cooldown for rapid fire; after the push count reaches the Pushs limit, it waits for the push counter to reset before working again.
